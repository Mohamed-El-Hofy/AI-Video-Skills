# مهارات إنتاج الفيديو بالذكاء الاصطناعي

تسع مهارات قابلة لإعادة الاستخدام مع Codex وClaude Code وAntigravity، ومحرك مستقل للإنتاج المحلي. المهارات تنسق السيناريو والصور والتعليق الصوتي والحركة والمونتاج والمراجعة والتصدير. الأصل الذي بُنيت عليه الفكرة لا يُعدّل ولا تُنسخ بياناته الخاصة.

## البداية

تحتاج Node.js بإصدار 22 أو أحدث وFFmpeg وFFprobe. المحرك الأساسي لا يحتاج `npm install`.

```sh
node cli/aiv.mjs doctor
node cli/aiv.mjs render examples/demo/project.json --out work/demo
node cli/aiv.mjs inspect work/demo/final.mp4
```

المثال بطاقات ألوان وصمت مقصود لاختبار التشغيل، وليس فيلمًا مولّدًا. اختبار `node scripts/smoke.mjs` يضيف حركة ومزجًا صوتيًا وترجمة عربية، باستخدام صورة اختبار ونغمات صناعية معلنة.

`READY` يعني أن فحوص المتطلبات نجحت، و`DEGRADED` يسمح بالإنتاج بالصور والصوت والتوقيتات الموجودة رغم غياب تكاملات اختيارية. `BLOCKED` يعني غياب متطلب أساسي. وجود إعداد لخدمة لا يثبت أنها تعمل.

إذا كان FFmpeg ناقصًا، يعرض `node cli/aiv.mjs setup ffmpeg` أمر التثبيت ويطلب كتابة `INSTALL`. التشغيل غير التفاعلي يرفض تلقائيًا. لا تُنزّل نماذج أو برامج أو متصفحات تلقائيًا.

## إضافة المهارات إلى برنامجك

من داخل المستودع، استبدل المسار بمجلد مشروع الفيديو:

```sh
node scripts/install-skills.mjs --agent codex --project "مسار المشروع"
node scripts/install-skills.mjs --agent claude --project "مسار المشروع"
node scripts/install-skills.mjs --agent antigravity --project "مسار المشروع"
```

اختر الأمر الخاص ببرنامجك. يتشارك Codex وAntigravity الحاليان مجلد `.agents/skills`، لذلك لا تكرر التثبيت في المجلد نفسه. للمهارات الشخصية الدائمة استخدم `--user` بدل `--project ...` صراحةً. لا يتم أي تثبيت بمجرد فتح المستودع. أعد تحميل قائمة المهارات في المضيف بعد التثبيت. احتفظ بالمستودع في مكانه، أو عيّن `AIV_HOME` إذا نقلته.

بعدها يمكنك طلب: «اعمل وثائقي خمس دقائق باللهجة المصرية عن أعماق المحيط، وافحص المتطلبات أولًا». لو الصور أو الصوت غير متاحين، سيُطلب منك توفيرهما أو الموافقة على إعداد مزود؛ لا يُدّعى إنتاج أصول لم تُنتج.

## الإنتاج الحقيقي

أنشئ `project.json` بأمر `init`، ثم استبدل البطاقات بصور مرخّصة وأضف ملفات الصوت. الإعدادات الخاصة تُمرّر عبر `--config providers.local.json`، والتوكنات عبر متغيرات البيئة. لا تُنسخ مفاتيح من برامج أخرى. محولات Remotion وWhisper وVoiceTuT وConcat والصور اختيارية.

شغّل `validate project.json --assets` قبل الرندر. استخدم `render` أو `resume` بنفس مجلد المخرجات. يتحقق الاستئناف من محتوى الملفات وصحة المقاطع؛ تعديل صورة أو فساد مقطع يستدعي إعادة إنتاجه. الصوت الأطول من المشهد يُرفض لتعديل التوقيت صراحةً.

المخرجات تشمل `final.mp4` و`captions.srt` وتقرير الإنتاج ونقاط الحفظ. العربية تُحفظ بترتيبها الصحيح، وتحتاج الترجمة المحروقة خطًا يدعمها وFFmpeg مع libass. الحركة المتاحة تكبير وتصغير وتحريك أفقي؛ الانتقالات قطع أو تلاشي عبر الأسود. العمق الحقيقي والانتقالات المتداخلة غير منفّذة في هذه النسخة.

نتائج التشغيل وحدودها موجودة في [تقرير التحقق](docs/VERIFICATION.md)، والتكاملات في [دليل المزودات](docs/PROVIDERS.md). لا تعتبر ملفات CI اختبارًا منفذًا على Linux وmacOS، ولا الاختبارات الوهمية إثباتًا لجودة صوت أو صورة حقيقية. [ملف التسليم](HANDOFF.md) يوضح الحالة وخطوات المتابعة لـAntigravity.

الترخيص Apache-2.0 للكود والمهارات الجديدة. الصور والأصوات والموسيقى والنماذج والأدوات الخارجية لها حقوقها المستقلة. لم يُنشر المستودع على GitHub، والنشر يحتاج موافقة صريحة.
