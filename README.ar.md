مجموعة مهارات تساعد وكيل الذكاء الاصطناعي على تنسيق إنتاج الفيديو: كتابة السيناريو، تجهيز الصور والتعليق الصوتي، تحريك الصور، المونتاج، مراجعة الجودة ثم تصدير MP4. يتولى المحرك المحلي خطوات الإنتاج المتكررة ويحفظ التقدم لاستئناف العمل بعد الانقطاع.

مُعدّة للعمل مع **Codex وClaude Code وGoogle Antigravity**، وتكاملات اختيارية مع **Remotion وFFmpeg وWhisper وVoiceTuT وConcat وتوليد الصور**. يمكنك استخدام صورك وتسجيلاتك، أو توصيل مزودات معتمدة عند الحاجة.

> **ما تم التحقق منه:** نجح 35 اختبارًا على Windows، ورندر واستئناف فعليان عبر FFmpeg وRemotion. ملفات Linux/macOS ومسارات تثبيت البرامج جاهزة؛ الاكتشاف الفعلي داخل المضيفات وجودة جميع مزودات التوليد لم تُختبر بالكامل. [التفاصيل والنتائج ←](docs/VERIFICATION.md)

## أمثلة: ماذا يمكنك إنتاجه؟

الأمثلة التالية **طلبات استخدام وشكل التسليم المتوقع**، وليست أفلامًا نُفّذت بالفعل. يلزم توفير الصور والصوت أو إعداد مزودات مناسبة قبل الإنتاج الحقيقي.

### ١. وثائقي قصير باللهجة المصرية

**اطلب من الوكيل:**

> اعمل وثائقي 60 ثانية عن الحياة في أعماق المحيط، باللهجة المصرية، رأسي 1080×1920. استخدم حركة هادئة وترجمة عربية. افحص المتطلبات أولًا، واسألني قبل أي تثبيت.

**ما الذي سيحدث؟** إعداد سيناريو بمصادر، تقسيمه إلى مشاهد، تجهيز الصور والصوت، قياس توقيت التسجيل، إضافة الحركة والترجمة، ثم المراجعة والتصدير.

**النتيجة المتوقعة:** `final.mp4` رأسي مدته دقيقة، وملف ترجمة، وقائمة بمصادر الأصول، وتقرير إنتاج. عند غياب مزود صور أو صوت، يطلب الوكيل أصولًا منك أو إعدادًا بموافقتك قبل استكمال تلك المرحلة.

### ٢. فيديو عرض منتج من صورك

**اطلب من الوكيل:**

> حوّل الصور الثلاث دي لفيديو عرض منتج 20 ثانية، مقاس مربع. حركة تكبير وتحريك بسيطة، وتعليقات عربية قصيرة، والموسيقى اللي أرفقتها، من غير تعليق صوتي. حافظ على ظهور المنتج كاملًا.

**ما الذي سيحدث؟** فحص الصور، اختيار القص الآمن، توزيع المشاهد والتعليقات على المدة، إضافة الحركة ومزج الموسيقى، ثم فحص التصدير.

**النتيجة المتوقعة:** فيديو 1080×1080 بصيغة H.264/AAC وتعليقات بتوقيتات محددة. يمكن استخدام FFmpeg بالأصول الموجودة دون تثبيت مولد صور أو صوت. يجب أن تكون الموسيقى مسموحًا لك باستخدامها.

### ٣. فيديو تعليمي بتسجيل جاهز

**اطلب من الوكيل:**

> اعمل شرح تعليمي 90 ثانية بالعرض من التسجيل العربي والرسومات دي. حافظ على الكلام كاملًا، وضيف ترجمة واضحة وسلّمني MP4 وSRT. استخدم Whisper لو مُعدّ بالفعل، وإلا ساعدني أجهز توقيتات يدويًا.

**ما الذي سيحدث؟** قياس التسجيل، تقسيمه إلى ملفات صوت للمشاهد عند الحاجة، توزيع الرسومات، تفريغ الكلام أو إدخال توقيتات يدوية، مراجعة النص، ثم الإنتاج.

**النتيجة المتوقعة:** فيديو 1920×1080، و`captions.srt` مُراجع، ومشروع قابل للاستئناف. لو الصوت أطول من المشهد، يرفض المحرك قصّه تلقائيًا ويطلب تعديل التوقيت صراحةً.

## لقطة من نتيجة تشغيل فعلية

![لقطة من اختبار FFmpeg الفعلي، بترجمة عربية متصلة فوق صورة تدرج صناعية](docs/assets/portable-smoke.png)

*هذه لقطة من اختبار تشغيل مدته أربع ثوانٍ: صورة تدرّج صناعية، حركة كاميرا، ترجمة عربية محروقة ومزج نغمات اختبار. ليست صورة مولّدة بالذكاء الاصطناعي أو تعليقًا صوتيًا بشريًا.*

لإنتاج نفس تجربة التشغيل:

```sh
node scripts/smoke.mjs
```

الفيديو الناتج في `work/smoke/output/final.mp4`. المواصفات المقاسة: **640×360، و24 إطارًا في الثانية، وH.264/AAC، ونحو أربع ثوانٍ**. إعادة التشغيل استخدمت المشهدين المحفوظين. ونجحت تجربة زمنية صناعية منفصلة لخمس دقائق؛ لا تُعدّ اختبار أداء لوثائقي طويل عالي الدقة.

## البداية السريعة

### المتطلبات

| المتطلب | استخدامه |
| --- | --- |
| Node.js 22 أو أحدث | تشغيل المحرك والأوامر وفحص المشاريع |
| FFmpeg وFFprobe | الرندر والصوت والتصدير وفحص الوسائط |
| FFmpeg مع libass وخط يدعم العربية | الترجمة العربية المحروقة |
| مزودات اختيارية | توليد الصور والصوت والتفريغ وRemotion وConcat |

المحرك الأساسي يستخدم مكتبات Node المدمجة، لذلك **لا يحتاج `npm install`**. النماذج والمتصفحات والخدمات الخارجية ليست مرفقة.

من مجلد المستودع:

```sh
# فحص المتطلبات دون تثبيت شيء.
node cli/aiv.mjs doctor

# إنتاج مثال بطاقات الألوان المرفق، ومدته أربع ثوانٍ.
node cli/aiv.mjs render examples/demo/project.json --out work/demo

# فحص الفيديو الناتج.
node cli/aiv.mjs inspect work/demo/final.mp4

# استئناف الإنتاج والتحقق من إعادة استخدام المشاهد.
node cli/aiv.mjs resume examples/demo/project.json --out work/demo
```

المثال المرفق بطاقات ألوان بلا تعليق صوتي عمدًا. لاختبار حركة الصور والصوت والترجمة معًا، استخدم أمر `smoke` السابق.

### كيف تقرأ نتيجة فحص البيئة؟

| الحالة | معناها | الخطوة التالية |
| --- | --- | --- |
| `READY` | فحوص المتطلبات نجحت | تجهيز الأصول وفحص المشروع |
| `DEGRADED` | بعض القدرات الاختيارية غائبة أو غير متحقق منها | الاستمرار بالأصول المتوفرة حيث يناسب الطلب |
| `BLOCKED` | متطلب أساسي ناقص أو غير متوافق | مراجعة الإعداد المطلوب والموافقة عليه |

إذا كان FFmpeg ناقصًا، يعرض `node cli/aiv.mjs setup ffmpeg` أمر التثبيت المحدد ويطلب كتابة `INSTALL`. التشغيل غير التفاعلي يرفضه. الخطط المتاحة winget على Windows وHomebrew ffmpeg-full على macOS وapt على Debian/Ubuntu؛ التوزيعات الأخرى تحتاج إعدادًا يدويًا مُراجعًا. النماذج والمتصفحات تحتاج موافقة منفصلة دائمًا.

## الاستخدام مع برنامجك

اختر الأمر الخاص ببرنامجك، واستبدل المسار بمجلد مشروع الفيديو:

```sh
node scripts/install-skills.mjs --agent codex --project "path/to/video-project"
node scripts/install-skills.mjs --agent claude --project "path/to/video-project"
node scripts/install-skills.mjs --agent antigravity --project "path/to/video-project"
```

لإضافة المهارات شخصيًا بحيث تكون متاحة عبر مشاريعك، عند طلب هذا النطاق صراحةً:

```sh
node scripts/install-skills.mjs --agent codex --user
```

استبدل `codex` بـ`claude` أو `antigravity` حسب برنامجك. المثبّت يرفض الكتابة فوق مهارات موجودة. يتشارك Codex وAntigravity الحاليان `.agents/skills` داخل المشروع؛ ثبّت مرة واحدة إذا كانا يستخدمان المجلد نفسه. Claude Code يستخدم `.claude/skills`. [المسارات الحالية والقديمة ←](docs/COMPATIBILITY.md)

أعد تحميل قائمة المهارات في المضيف بعد التثبيت. احتفظ بالمستودع في مكانه، أو أعد التثبيت/عيّن `AIV_HOME` إذا نقلته. انقل المجلدات كاملة بمراجعها ومشغلاتها؛ نسخ `SKILL.md` وحده لا يكفي. فتح المستودع لا يثبّت المهارات تلقائيًا.

## إنتاج مشروع بأصولك

1. أنشئ المشروع: `node cli/aiv.mjs init my-video/project.json`.
2. استبدل بطاقات التجربة بمسارات صور نسبية للمشروع، وأضف ملفات التعليق الصوتي عند الحاجة.
3. أضف توقيتات ترجمة مُراجعة، وأعدّ المزودات للقدرات الناقصة فقط.
4. افحص المشروع ثم أنتج الفيديو:

```sh
node cli/aiv.mjs validate my-video/project.json --assets
node cli/aiv.mjs render my-video/project.json --out work/my-video
node cli/aiv.mjs inspect work/my-video/final.mp4
```

لتوليد أصول جديدة، انسخ `examples/providers.example.json` إلى ملف خاص باسم `providers.local.json` واضبط المزودات التي ستستخدمها، ثم:

```sh
node cli/aiv.mjs prepare my-video/project.json --config providers.local.json
```

ينتج `prepare` الصور والصوت الناقصين عبر المزودات المُعدّة فقط. احفظ التوكنات في متغيرات البيئة المحددة صراحةً. [صيغة المشروع ←](docs/PROJECT_FORMAT.md) · [إعداد التكاملات ←](docs/PROVIDERS.md)

### شكل الملفات الناتجة

```text
work/my-video/
├── final.mp4                 # الفيديو النهائي H.264/AAC
├── captions.srt              # ملف الترجمة
├── captions.ass              # تنسيق الترجمة المحروقة
├── production-report.json    # النتائج وعدد المشاهد المنتجة/المستخدمة
├── checkpoint.json           # حالة الإنتاج للاستئناف
└── scene-<id>-<hash>.mp4      # نسخ المشاهد المتحقق منها
```

أوضاع الترجمة: `sidecar` أو`burn` أو`none`. يمكن تحديد خط محلي مع اسمه الداخلي `fontFamily`. العربية محفوظة بترتيب Unicode الصحيح. الحركة الحالية تكبير وتصغير وتحريك أفقي، والانتقالات قطع أو تلاشي عبر الأسود. العمق الحقيقي والحركة ثلاثية الأبعاد والانتقالات المتداخلة خارج نطاق النسخة 0.1.

### استكمال الإنتاج بعد انقطاع

```sh
node cli/aiv.mjs resume my-video/project.json --out work/my-video
```

استخدم مجلد المخرجات نفسه. يفحص المحرك محتوى المدخلات وبصمات المقاطع قبل إعادة استخدامها، ويعيد إنتاج المشهد المتأثر إذا تغيّر أصله أو تلف ملفه. احتفظ بالمدخلات خارج مجلد المخرجات. قفل الإنتاج يمنع التشغيل المتزامن؛ تحقّق من توقف العملية القديمة قبل إزالة قفل عالق.

## التكاملات الاختيارية

| الأداة | وظيفتها | البديل |
| --- | --- | --- |
| FFmpeg/FFprobe | الرندر والصوت والتصدير والفحص الأساسي | مطلوبان لهذا المحرك |
| Remotion | محرك مشاهد اختياري بمتصفح موجود | رندر FFmpeg |
| Whisper | تفريغ بنموذج محلي إلى توقيتات ترجمة | توقيتات يدوية مُراجعة |
| VoiceTuT | إنتاج التعليق الصوتي عبر جسر المهام المُعدّ | تسجيل جاهز أو جسر مُراجع |
| A1111 / جسر صور | توليد صور المشاهد | صور مرخّصة جاهزة |
| Concat | تسليم خطة زمنية بصيغة تبادل | المونتاج والتصدير داخل المحرك |

ملف Concat صيغة تبادل معلنة؛ لا يُعدّ استيرادًا أصليًا متحققًا منه. يلزم استخدام مخطط أدوات المضيف الفعلي للتحرير داخل Concat. وجود عنوان خدمة في الإعدادات لا يثبت جاهزية الخدمة أو النموذج. [دليل التكاملات ←](docs/PROVIDERS.md)

## التحقق وحدود النسخة

```sh
node --test
node scripts/check-skills.mjs
node scripts/smoke.mjs
```

- **نُفّذ:** 35 اختبارًا ناجحًا على Windows، وفحوص المهارات التسع، ورندر واستئناف FFmpeg وRemotion، ورفض وسائط تالفة واستعادة مقاطع، وتجربة زمنية صناعية لخمس دقائق.
- **جُهّز:** CI لأنظمة Linux/macOS وإصداري Node22/24، ومسارات تثبيت المهارات ومشغلاتها.
- **يحتاج تحققًا فعليًا:** اكتشاف المضيفات الثلاثة للمهارات، وجودة VoiceTuT وWhisper ونماذج الصور الحقيقية، واستيراد Concat الأصلي، وإنتاج وثائقي حقيقي كامل مدته 5–20 دقيقة.

راجع الترجمة والحركة واستمع للصوت قبل التسليم. الاختبارات الوهمية ومواصفات الملف لا تثبت جودة النطق أو مزامنة الكلام. [سجل التحقق الكامل ←](docs/VERIFICATION.md)
