# Contributing

Keep the engine independent of personal paths, source-studio files and installed optional providers. Node 22+; no mandatory npm dependencies. Add a regression test for changes affecting output, state, provider contracts or installation behavior. Run node --test, node scripts/check-skills.mjs and node scripts/smoke.mjs. Record actual platform/provider coverage separately from mocks.

Each skill must retain its folder name/frontmatter match, specific discovery description, bundled runtime launcher/reference and evidence-based handoff. Do not silently expand tool permissions, install models or add publication side effects. Changes to checkpoint semantics need a version/cache invalidation decision. Keep source/license attribution for any newly introduced component.
